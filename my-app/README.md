# Almajdouie Foundation — application

This is the Next.js application. **Setup, environment variables and commands are documented in the [repository README](../README.md).**

```bash
pnpm install     # pnpm only — the postinstall step copies MapLibre's worker
cp .env.example .env
pnpm dev         # → http://localhost:3000
```
